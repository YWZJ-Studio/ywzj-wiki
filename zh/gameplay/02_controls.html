玩法指南

基础操作

进入与退出载具

  • 上车 — 手持载具刷怪蛋右键地面生成载具，右键载具进入
  • 下车 — 按 J 键离开载具
  • 切换座位 — 按 ` 键（Tab上方）在载具的各个座位间切换

燃油系统

  • 载具消耗燃油运作，油箱容量由 energy_info.energy_capacity 决定
  • 给载具加油：手持 燃料桶（ywzj_vehicle:fuel_tank）右键载具
  • 燃料桶可用工作台补充（煤炭+燃料桶）
  • 配置文件 infiniteFuel 设为 true 可关闭燃油消耗

提示

燃油液体（ywzj_vehicle:fuel）默认被识别为燃料，lava（岩浆）和任何ID包含 gas 的液体也可用作燃料。可通过配置文件 fuelNameWhiteList 自定义。

维修系统

载具受损后可用 维修工具（repair_tool）修理：

  • 手持维修工具右键载具恢复生命值
  • 维修工具也可用作近战武器，对实体造成伤害

3D打印机

Machine Max 方块用于制造载具：

  1. 摆放方块后右键打开GUI
  2. 按配方放入所需材料
  3. 点击打印按钮
  4. 等待进度条完成
  5. 取出载具刷怪蛋

手办盒

手办盒（Figure Box）用于收纳和展示实体：

  • 收纳 — 手持手办盒右键实体将其捕获
  • 放置 — 手持装有实体的手办盒右键地面放置展示方块
  • 取出 — 右键展示方块取回实体
  • 配置黑名单 — config/limitless_vehicle/figure_box_capture_blacklist.txt

提示

配置 figureBoxOnlyCaptureVehicle 为 true 可限制手办盒只能收纳载具实体。

雷达与RWR

  • 雷达 — 载具的雷达部件自动扫描范围内实体，锁定后武器可追踪目标
  • RWR（雷达告警接收机） — 当载具被敌方雷达锁定时发出警告
  • 导弹告警 — 启用了 with_warning_receiver 的载具可探测来袭导弹

热成像

按 4 键开启热成像模式，画面会渲染为热感视图，便于发现目标。

快速索降

支持索降的直升机可让乘客通过绳索快速下到地面：

  • 需在载具配置中启用 fast_roping: true 并指定索降用的门部件
  • 乘客在对应门位置可进行索降动作

UAV无人机

四轴无人机（Quadcopter）可通过UAV控制器远程操控：

  • 手持 UAV控制器（ywzj_vehicle:uav_controller）右键无人机进行配对
  • 配对后玩家进入观察者模式控制无人机
  • 无人机支持挂载货物(←键释放货物)
